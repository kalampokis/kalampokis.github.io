Εισαγωγή στην Python

Ένας διαδραστικός οδηγός για την τάξη και το σπίτι. Ο κώδικας τρέχει μέσα στον browser σου: άλλαξέ τον, πάτησε Τρέξε (ή Ctrl+Enter) και δες τι γίνεται. Σε κάθε βήμα υπάρχουν κουίζ «τι θα τυπώσει;» και ασκήσεις που ελέγχονται αυτόματα.

1. Το περιβάλλον της Python

Στο DataCamp γράφεις κώδικα σε ένα script (script.py) και βλέπεις το αποτέλεσμα στην κονσόλα (IPython Shell). Εδώ το παράθυρο κώδικα παίζει τον ρόλο του script και το γκρι κουτί από κάτω τον ρόλο της κονσόλας.

Η print() εμφανίζει μια τιμή. Ό,τι ακολουθεί το # είναι σχόλιο (comment): η Python το αγνοεί, είναι για τους ανθρώπους.

ΔΟΚΙΜΑΣΕΒάλε # μπροστά από την τελευταία print και ξανατρέξε. Μετά υπολόγισε 2 + 3 * 4 και (2 + 3) * 4: η προτεραιότητα είναι η μαθηματική.

Υπολόγισε πόσο γίνονται 100 ευρώ με 10% ετήσιο τόκο μετά από 7 χρόνια, δηλαδή 100 * 1.1 ** 7, και τύπωσέ το.

2. Μεταβλητές και τύποι δεδομένων

Μια μεταβλητή (variable) είναι ένα όνομα που δείχνει σε μια τιμή: savings = 100. Το = σημαίνει «ανάθεση», όχι ισότητα. Τα ονόματα ξεχωρίζουν πεζά/κεφαλαία (case-sensitive).

Οι τέσσερις βασικοί τύποι (data types)

ΤύποςΤι είναιΠαράδειγμα
intακέραιος (integer)x = 42
floatδεκαδικός (floating point), με τελείαy = 1.75
strκείμενο (string), σε εισαγωγικάname = "Maria"
boolλογική τιμή (boolean): True ή Falseok = True

Η συνάρτηση type() σου λέει τον τύπο. Ο τύπος καθορίζει τη συμπεριφορά: το + προσθέτει αριθμούς αλλά ενώνει strings.

ΔΟΚΙΜΑΣΕΓράψε print("total: " + 3). Διάβασε το μήνυμα σφάλματος: η Python δεν ξέρει αν θες πρόσθεση ή ένωση. Διόρθωσέ το με str(3).

4. Τμήματα λίστας (slicing) και αλλαγές

Με my_list[start:end] παίρνεις πολλά στοιχεία: ο start περιλαμβάνεται, ο end όχι. Αν παραλείψεις το start ξεκινά από την αρχή, αν παραλείψεις το end πάει ως το τέλος. Δοκίμασε x[1:3], x[:2], x[2:], x[-2:]:

Αλλαγή, προσθήκη, διαγραφή

ΓΙΑΤΙ ΕΧΕΙ ΣΗΜΑΣΙΑΤο b = a δίνει δεύτερο όνομα στην ίδια λίστα, οπότε μια αλλαγή μέσω του b φαίνεται και στο a. Για ανεξάρτητο αντίγραφο γράψε list(a) ή a[:]. Είναι από τις πιο συχνές πηγές «μυστήριων» σφαλμάτων.

5. Συναρτήσεις (functions) και μέθοδοι (methods)

Μια συνάρτηση είναι έτοιμος κώδικας με όνομα: output = function_name(input). Ήδη ξέρεις τις print() και type(). Άλλες χρήσιμες: len(), max(), round(), sorted(), help().

Μέθοδοι: συναρτήσεις που «ανήκουν» σε αντικείμενα

Κάθε τιμή στην Python είναι αντικείμενο (object) και κάθε τύπος έχει τις δικές του μεθόδους. Καλούνται με τελεία: sister.upper(), fam.index("emma").

ΣΥΧΝΟ ΛΑΘΟΣfam = fam.append("anna") κάνει τη fam ίση με None, γιατί η append() δεν επιστρέφει τίποτα· αλλάζει τη λίστα επί τόπου. Γράψε απλώς fam.append("anna"). Δοκίμασέ το παραπάνω για να δεις τι γίνεται.

6. Πακέτα (packages)

Ένα πακέτο είναι μια συλλογή από έτοιμες συναρτήσεις, μεθόδους και τύπους. Για ανάλυση δεδομένων: NumPy (αριθμητικοί πίνακες), pandas (πίνακες δεδομένων), Matplotlib (γραφήματα), scikit-learn (μηχανική μάθηση). Τα εγκαθιστάς μία φορά (pip install numpy) και τα εισάγεις (import) σε κάθε script.
