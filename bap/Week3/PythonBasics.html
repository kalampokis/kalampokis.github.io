Εισαγωγή στην Python

Ένας διαδραστικός οδηγός για την τάξη και το σπίτι, σε 8 βήματα. Ο κώδικας τρέχει μέσα στον browser σου: άλλαξέ τον, πάτησε Τρέξε (ή Ctrl+Enter) και δες τι γίνεται. Σε κάθε βήμα υπάρχουν κουίζ «τι θα τυπώσει;» και ασκήσεις που ελέγχονται αυτόματα.

1. Το περιβάλλον της Python

Κώδικα Python γράφουμε σε ένα script (αρχείο .py ή κελί σε Jupyter / Google Colab) και βλέπουμε το αποτέλεσμα στην κονσόλα (console). Εδώ το σκούρο παράθυρο παίζει τον ρόλο του script και το ανοιχτό κουτί από κάτω τον ρόλο της κονσόλας. Σε script, ό,τι θέλεις να δεις πρέπει να το τυπώσεις με print().

Η print() εμφανίζει μια τιμή. Ό,τι ακολουθεί το # είναι σχόλιο (comment): η Python το αγνοεί, είναι για τους ανθρώπους.

ΔΟΚΙΜΑΣΕΒάλε # μπροστά από την τελευταία print και ξανατρέξε. Μετά υπολόγισε 2 + 3 * 4 και (2 + 3) * 4: η προτεραιότητα είναι η μαθηματική.

Υπολόγισε πόσο γίνονται 100 ευρώ με 10% ετήσιο τόκο μετά από 7 χρόνια, δηλαδή 100 * 1.1 ** 7, και τύπωσέ το.

2. Μεταβλητές και τύποι δεδομένων

Μια μεταβλητή (variable) είναι ένα όνομα που δείχνει σε μια τιμή: revenue = 1250. Το = σημαίνει «ανάθεση», όχι ισότητα. Τα ονόματα ξεχωρίζουν πεζά/κεφαλαία (case-sensitive).

Οι τέσσερις βασικοί τύποι (data types)

ΤύποςΤι είναιΠαράδειγμα
intακέραιος (integer)stock = 42
floatδεκαδικός (floating point), με τελείαprice = 25.5
strκείμενο (string), σε εισαγωγικάproduct = "Laptop"
boolλογική τιμή (boolean): True ή Falsein_stock = True

Η συνάρτηση type() σου λέει τον τύπο. Ο τύπος καθορίζει τη συμπεριφορά: το + προσθέτει αριθμούς αλλά ενώνει strings.

ΔΟΚΙΜΑΣΕΓράψε print("total: " + 3). Διάβασε το μήνυμα σφάλματος: η Python δεν ξέρει αν θες πρόσθεση ή ένωση. Διόρθωσέ το με str(3).

Κείμενο με τιμές μέσα: f-strings

Αντί για αλυσίδες από + και str(), γράφεις f"...{μεταβλητή}...". Μέσα στα άγκιστρα μπορείς να ζητήσεις μορφοποίηση: {x:.2f} δύο δεκαδικά, {x:,} διαχωριστικό χιλιάδων, {x:.1%} ποσοστό.

Συγκρίσεις: από πού έρχονται τα True και False

Οι τελεστές == != < <= > >= δίνουν boolean. Τα and, or, not τα συνδυάζουν. Προσοχή: = αναθέτει, == συγκρίνει.

Άσκηση 2

Τα έσοδα είναι 1250 και αυξάνονται 8% τον χρόνο. Συμπλήρωσε τον κώδικα ώστε να τυπώνει ακριβώς: Revenue 1250 now, 1836.66 in 5 years. Θυμήσου: αριθμός + string δίνει σφάλμα, χρειάζεσαι str() ή f-string.

4. Τμήματα λίστας (slicing) και αλλαγές

Με my_list[start:end] παίρνεις πολλά στοιχεία: ο start περιλαμβάνεται, ο end όχι. Αν παραλείψεις το start ξεκινά από την αρχή, αν παραλείψεις το end πάει ως το τέλος. Δοκίμασε x[1:3], x[:3] (πρώτο τρίμηνο), x[3:] (δεύτερο τρίμηνο), x[-2:]:

Αλλαγή, προσθήκη, διαγραφή

ΓΙΑΤΙ ΕΧΕΙ ΣΗΜΑΣΙΑΤο backup = sales δίνει δεύτερο όνομα στην ίδια λίστα, οπότε μια αλλαγή μέσω του backup φαίνεται και στο sales. Για ανεξάρτητο αντίγραφο γράψε list(sales) ή sales[:]. Είναι από τις πιο συχνές πηγές «μυστήριων» σφαλμάτων.

5. Συναρτήσεις (functions) και μέθοδοι (methods)

Μια συνάρτηση είναι έτοιμος κώδικας με όνομα: output = function_name(input). Ήδη ξέρεις τις print() και type(). Άλλες χρήσιμες: len(), max(), round(), sorted(), help().

Μέθοδοι: συναρτήσεις που «ανήκουν» σε αντικείμενα

Κάθε τιμή στην Python είναι αντικείμενο (object) και κάθε τύπος έχει τις δικές του μεθόδους. Καλούνται με τελεία: city.upper(), customers.index("nikos").

ΣΥΧΝΟ ΛΑΘΟΣcustomers = customers.append("giorgos") κάνει τη customers ίση με None, γιατί η append() δεν επιστρέφει τίποτα· αλλάζει τη λίστα επί τόπου. Γράψε απλώς customers.append("giorgos"). Δοκίμασέ το παραπάνω για να δεις τι γίνεται.
