Ηλεκτρονικές Υπηρεσίες στις Τουριστικές Επιχειρήσεις · Εργαστήρια Tableau, Εβδομάδες 2, 3 και 5

Tableau σε μία σελίδα

Ό,τι χρησιμοποιήσαμε στα τρία εργαστήρια, με τη διαδρομή στο μενού και τους τύπους όπως τους γράψαμε. Για να το έχεις δίπλα σου όταν δουλεύεις με δικά σου δεδομένα. Οι αναλυτικοί οδηγοί: Εβδ. 2 · Εβδ. 3 · Εβδ. 5.

1 · Τα δύο είδη πεδίωνΔιάσταση και μετρούμενο μέγεθος

Διάσταση (μπλε, dimension): κατηγορία που κόβει τα δεδομένα: Hotel, Country, Market Segment, ημερομηνία. Μετρούμενο μέγεθος (πράσινο, measure): αριθμός που αθροίζεται: ADR, Nights, Revenue.

Κάθε μετρούμενο μέγεθος μπαίνει στο φύλλο με μια συνάθροιση (aggregation): SUM, AVG, COUNT, COUNTD. Αλλαγή: βελάκι του pill › Measure › Average. Το πρώτο πράγμα που διαβάζεις είναι το pill, όχι ο αριθμός: SUM(ADR) δεν σημαίνει τίποτα.

2 · Η οθόνηΡάφια, Marks, πάνελ

  • Columns / Rows: τι πάει οριζόντια / κάθετα.
  • Κάρτα Marks: τύπος (Bar, Line, Square, Circle) και Color, Size, Label, Text, Detail, Tooltip. Σύρε ένα πεδίο πάνω σε ό,τι θέλεις να το ελέγχει.
  • Show Me (πάνω δεξιά): προτείνει γράφημα για τα πεδία που έχεις επιλέξει.
  • Ημερομηνία: βελάκι του pill › πάνω ομάδα = διακριτό (μπλε: «Μάιος», όλα τα χρόνια μαζί), κάτω ομάδα = συνεχές (πράσινο: «May 2016», άξονας χρόνου).
  • Πάνελ Analytics (δίπλα στο Data): Trend Line, Forecast, Average Line, Reference Line.

3 · Τρία επίπεδαΦίλτρα

  • Φίλτρο φύλλου: σύρε πεδίο στο ράφι Filters. Διαστάσεις με λίστα, μετρούμενα μεγέθη με εύρος, Top N από την καρτέλα Top.
  • Κάρτα φίλτρου (ο χρήστης διαλέγει): pill › Show Filter· μορφή από το βελάκι της κάρτας (Single Value dropdown, Multiple Values list).
  • Φίλτρο dashboard: βελάκι της κάρτας › Apply to Worksheets › All Using This Data Source. Χωρίς αυτό φιλτράρει μόνο το φύλλο όπου φτιάχτηκε.
  • Ενέργεια φίλτρου: Dashboard › Actions › Add Action › Filter: κλικ σε ένα γράφημα φιλτράρει τα άλλα. Προσοχή: ένα KPI «πληρότητα» φιλτραρισμένο σε ένα κανάλι δείχνει μερίδιο, όχι πληρότητα.

4 · Ό,τι ξέρει ο χρήστης, όχι τα δεδομέναΠαράμετροι

Πάνελ Data › βελάκι › Create Parameter: όνομα, τύπος (Integer / Float), τρέχουσα τιμή, εύρος και βήμα. Μετά Show Parameter για το slider. Μπαίνει μέσα σε τύπους σαν πεδίο: [Rooms].

Δύο που χρησιμοποιήσαμε: Rooms (Integer, 200, 50–600, βήμα 10) και Commission (Float, 0,18, 0,10–0,30, Percentage). Ποσοστό = 0,18, όχι 18: αλλιώς το 1 − 18 βγάζει αρνητικά έσοδα.

Στην παρουσίαση η παράμετρος λέγεται δυνατά: «με την υπόθεση 200 δωματίων…». Αν η πληρότητα βγαίνει πάνω από 100%, φταίει η υπόθεση, όχι το Tableau.

5 · Πάνελ AnalyticsΤάση και πρόβλεψη

Trend Line › Linear σε άξονα συνεχούς χρόνου. Ποντίκι πάνω στη γραμμή: κλίση, R² (0–1, πόσο «εξηγεί» η ευθεία), P-value. Η τάση περιγράφει το παρελθόν, δεν υπόσχεται το μέλλον.

Forecast σε γραμμή με MONTH continuous. Analysis › Forecast › Forecast Options: μήκος (Exactly 12 Months), Ignore last 1 (ο τελευταίος μήνας θεωρείται ατελής). Η σκιασμένη ζώνη είναι η πληροφορία: «1.900–2.700», όχι «2.300». Describe Forecast για μοντέλο και MAPE. Ξέρει μόνο το παρελθόν της ίδιας της γραμμής.

6 · Πολλά μετρούμενα μεγέθη μαζίMeasure Names / Measure Values

Measure Names (τελευταίο στις διαστάσεις) και Measure Values (τελευταίο στα μετρούμενα μεγέθη). Measure Names στο Rows + Measure Values στο Text = πίνακας δεικτών· στην κάρτα Measure Values σύρε έξω ό,τι δεν θέλεις.

Highlight table: Marks Square, Measure Values και στο Color, υπόμνημα › Use Separate Legends. Δύο στήλες μπάρες (μικτά/καθαρά): Measure Values στο Columns, όχι στο Color (αλλιώς στοιβάζονται).

7 · Νέα πεδία από τα παλιάΥπολογιζόμενα πεδία (Create Calculated Field)

Cancellation Rate SUM(IF [Canceled] = 'Yes' THEN 1 ELSE 0 END) / COUNT([Booking ID])
Revenue Kept (έσοδα που πραγματοποιήθηκαν) IF [Canceled] = 'No' THEN [Revenue] END
Room Nights Sold SUM(IF [Canceled] = 'No' THEN [Nights] END)
Days in Period COUNTD([Arrival Date])
Occupancy [Room Nights Sold] / ([Rooms] * [Days in Period])
RevPAR SUM(IF [Canceled] = 'No' THEN [Revenue] END) / ([Rooms] * [Days in Period])
Lead Time Group (ομάδες με επιχειρησιακό νόημα· ο αριθμός μπροστά για τη σειρά) IF [Lead Time (days)] <= 7 THEN '1 · 0–7 μέρες' ELSEIF [Lead Time (days)] <= 30 THEN '2 · 8–30 μέρες' ELSEIF [Lead Time (days)] <= 90 THEN '3 · 1–3 μήνες' ELSEIF [Lead Time (days)] <= 180 THEN '4 · 3–6 μήνες' ELSE '5 · πάνω από 6 μήνες' END
Net Revenue (πάνω στο Revenue Kept, όχι στο Revenue: οι ακυρωμένες δεν πληρώνουν προμήθεια) [Revenue Kept] * (1 - IF [Market Segment] = 'Online TA' OR [Market Segment] = 'Offline TA/TO' THEN [Commission] ELSE 0 END)

Κανόνες: IF … THEN … ELSEIF … ELSE … END· κείμενο σε μονά εισαγωγικά· πεδία σε αγκύλες· «The calculation is valid» πριν το OK. Ένα πεδίο που επιστρέφει κείμενο γίνεται διάσταση, ένα που επιστρέφει αριθμό μετρούμενο μέγεθος. Έλεγχος λογικής πάντα: καθαρά < μικτά, πληρότητα ≤ 100%, ADR δεκάδες ή εκατοντάδες ευρώ.

8 · Πάνω στα αθροισμένα κελιάΥπολογισμοί πίνακα (table calculations)

Δεν δημιουργούν πεδίο· υπολογίζουν πάνω στο φύλλο όπως είναι, συγκρίνοντας κελί με κελί. Βελάκι του pill › Quick Table Calculation: Percent Difference, Running Total, Percent of Total, Rank.

Η παγίδα είναι η κατεύθυνση: Compute Using. «Ίδιος μήνας πέρυσι» = Percent Difference με Compute Using › Year· αλλιώς συγκρίνει με τον προηγούμενο μήνα. Το pill αποκτά τριγωνάκι Δ.

9 · ΠαράδοσηΔημοσίευση και εξαγωγή

  • Tableau Public: File › Save to Tableau Public (desktop) ή Publish (web). Το link από το κουμπί Share.
  • Αρχείο: File › Export Packaged Workbook (.twbx, περιέχει και τα δεδομένα).
  • Εικόνα / PDF / PowerPoint: Dashboard › Export Image, File › Print to PDF, File › Export as PowerPoint. Στο Public: κουμπί Download.
ΔΗΜΟΣΙΟ ΣΗΜΑΙΝΕΙ ΔΗΜΟΣΙΟΌ,τι ανεβαίνει στο Tableau Public το βλέπει και το κατεβάζει όποιος θέλει, μαζί με τα δεδομένα. Ποτέ πραγματικά δεδομένα πελατών ή της επιχείρησης· ανωνυμοποίηση ή Tableau Desktop/Server. Θα το ξαναδούμε στην ενότητα για GDPR.

10 · Μετά το μάθημαΔικά σου δεδομένα

  • Connect › Microsoft Excel ή Text file (CSV). Μία γραμμή επικεφαλίδων, μία γραμμή ανά εγγραφή (κράτηση, διανυκτέρευση, κριτική), χωρίς συγχωνευμένα κελιά και σύνολα στο τέλος.
  • Αν το Excel είναι «μορφοποιημένη αναφορά»: τσέκαρε Use Data Interpreter. Μήνες σε στήλες; Επίλεξέ τες › Pivot.
  • Έλεγξε τους τύπους στη σελίδα Data Source (ημερομηνία ως ημερομηνία, αριθμοί ως αριθμοί, χώρα με το εικονίδιο σφαίρας)· κόμμα/τελεία στα δεκαδικά είναι η συνηθέστερη αιτία για «Null».
  • Πηγές που αξίζουν: εξαγωγή από το PMS ή τον channel manager, το Google Analytics (επόμενες εβδομάδες), κριτικές (ενότητα φήμης), ΕΛΣΤΑΤ/INSETE για τον κλάδο.

11 · Από τα φύλλα στην οθόνη και στην αφήγησηDashboard και Story

Dashboard (εικονίδιο κάτω, New Dashboard). Size › Fixed (Generic Desktop ή 1200×800). Objects: Horizontal / Vertical container, Text, Blank. KPI tile = φύλλο με ένα μετρούμενο μέγεθος στο Text, γραμματοσειρά 36+.

Έξι κανόνες: ένα ερώτημα για έναν αναγνώστη (3–5 γραφήματα) · οι μεγάλοι αριθμοί πάνω αριστερά · τίτλοι-συμπεράσματα με αριθμό μέσα («Οι κρατήσεις 6+ μήνες πριν ακυρώνονται 6 φορές συχνότερα») · ένα χρώμα = μία έννοια, το σημαντικό με χρώμα, τα υπόλοιπα γκρίζα · χωρίς θόρυβο (πλέγμα, περιγράμματα, πίτες πάνω από 3 κομμάτια, 8 ψηφία χωρίς διαχωριστικό) · σταθερό μέγεθος και φίλτρα Apply to All. Μορφοποίηση: Format › Numbers (Percentage, Display units Millions).

Story (New Story). Size ίδιο με το dashboard. Κάθε σημείο: ένα φύλλο ή dashboard + λεζάντα = το συμπέρασμα. Update αν αλλάξεις φίλτρο/παράμετρο μέσα στο σημείο. Πλοήγηση: Caption boxes ή Numbers. Presentation mode: F7.

Η σειρά: συμπέρασμα πρώτα → τι συνέβη → γιατί → πού κινδυνεύουμε → τι προτείνω (απόφαση, κόστος, ρίσκο) → τι περιμένουμε → τι δεν ξέρουμε. Πέντε λεπτά, ένα σημείο ανά λεπτό, ένας αριθμός ανά οθόνη, οι υποθέσεις δυνατά.
